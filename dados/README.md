# dados/

Vazio até o marco D2 (importador do Código Penal). Cada norma ganha uma
subpasta em `br/<esfera>/<tipo>/<identificador>/` com `norma.json`,
`estrutura.json` e `dispositivos.json` — ver o schema em `../schema/` e a
convenção de IDs em `../docs/convencao-ids.md`. `indice.json`, na raiz
desta pasta, lista as normas disponíveis.
