# dados/

Cada norma ganha uma subpasta em `br/<esfera>/<tipo>/<identificador>/` com
`norma.json`, `estrutura.json` e `dispositivos.json` — ver o schema em
`../schema/` e a convenção de IDs em `../docs/convencao-ids.md`.
`indice.json`, na raiz desta pasta, lista as normas disponíveis.

Por enquanto só o Código Penal (`br/federal/decreto-lei/1940-2848/`), e só
a Parte Geral (Art. 1º–120) — ver `../docs/parte-especial-pendente.md`.
Gerado por `../pipeline/importar-parte-geral.mjs` a partir do snapshot em
`../snapshots/`, nunca editado à mão.
